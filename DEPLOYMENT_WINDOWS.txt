🖥️  ИНСТРУКЦИЯ ДЛЯ WINDOWS

════════════════════════════════════════════════════════════════════════════

ТРЕБОВАНИЯ:
- Node.js 18+ (загрузить с https://nodejs.org)
- Git for Windows (загрузить с https://git-scm.com)
- Code Editor (VS Code рекомендуется)

════════════════════════════════════════════════════════════════════════════

ШАГ 1: УСТАНОВКА DEPENDENCIES
────────────────────────────────────────────────────────────────────────────

1. Распакуйте архив в нужное место
2. Откройте PowerShell или Command Prompt в папке проекта
3. Выполните команду:

   npm install --legacy-peer-deps

⏱️  Это займет 2-3 минуты

════════════════════════════════════════════════════════════════════════════

ШАГ 2: ЛОКАЛЬНАЯ РАЗРАБОТКА
────────────────────────────────────────────────────────────────────────────

1. Запустите dev сервер:

   npm run dev

2. Откройте в браузере:

   http://localhost:3000

3. Для остановки нажмите Ctrl + C в PowerShell

════════════════════════════════════════════════════════════════════════════

ШАГ 3: PRODUCTION BUILD
────────────────────────────────────────────────────────────────────────────

1. Соберите проект:

   npm run build

2. Запустите production версию:

   npm start

3. Откройте в браузере:

   http://localhost:3000

════════════════════════════════════════════════════════════════════════════

ШАГ 4: DEPLOYMENT НА VERCEL
────────────────────────────────────────────────────────────────────────────

ВАРИАНТ A - Через GitHub (РЕКОМЕНДУЕТСЯ):

1. Создайте GitHub аккаунт (https://github.com)

2. В PowerShell выполните:

   git config --global user.name "Your Name"
   git config --global user.email "your@email.com"

3. Инициализируйте Git репозиторий:

   git init
   git add .
   git commit -m "Initial commit: Yansi.IO production ready"

4. Создайте репозиторий на GitHub

5. Загрузите код:

   git remote add origin https://github.com/YOUR_USERNAME/yansi-nextjs.git
   git branch -M main
   git push -u origin main

6. Откройте Vercel (https://vercel.com)

7. Нажмите "Add New Project"

8. Импортируйте GitHub репозиторий

9. Vercel автоматически обнаружит Next.js конфигурацию

10. Нажмите Deploy

ВАРИАНТ B - Через Vercel CLI:

1. Установите Vercel CLI:

   npm install -g vercel

2. Авторизуйтесь:

   vercel login

3. Задеплойте:

   vercel --prod

════════════════════════════════════════════════════════════════════════════

🔐 ENVIRONMENT VARIABLES (важно для Vercel!)
────────────────────────────────────────────────────────────────────────────

1. В Vercel Project Settings → Environment Variables добавьте:

   TELEGRAM_BOT_TOKEN=xxx (запросить у автора)
   TELEGRAM_CHAT_ID=-5556191834
   NEXT_PUBLIC_SITE_URL=https://yan-si.io

2. ОБЯЗАТЕЛЬНО: Используйте НОВЫЙ Telegram Bot Token
   (старый токен экспонирован и должен быть заменен)

🆘 РЕШЕНИЕ ПРОБЛЕМ
────────────────────────────────────────────────────────────────────────────

Проблема: "npm not found"
Решение: Переустановите Node.js с https://nodejs.org

Проблема: "Port 3000 in use"
Решение: 
   taskkill /PID <process_id> /F
   или используйте другой port: npm run dev -- -p 3001

Проблема: "Git not found"
Решение: Переустановите Git с https://git-scm.com

Проблема: Build ошибка
Решение:
   rm -r node_modules .next
   npm install --legacy-peer-deps
   npm run build
